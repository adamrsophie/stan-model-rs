# stan-model-rs

A Rust-native runtime that executes Stan models: the execution contract between models
compiled by [stanc-rs](https://github.com/adamrsophie/stanc-rs), the mathematics of
[stanmath-rs](https://github.com/adamrsophie/stanmath-rs), and inference algorithms.

stan-model-rs is an independent, unofficial project. It is not a sampler and not a compiler. It
owns what sits between them:

* model metadata, parameter names, and Stan's flattening order;
* data input in CmdStan's JSON format, with shape and constraint validation;
* the composition of constraining transforms and their Jacobian adjustments;
* log density, gradient, Hessian, and Hessian-vector product evaluation;
* transformed parameters, generated quantities, and explicit random number streams;
* structured errors that tell a rejected proposal from a fatal problem.

## Example

```rust
use stan_model_rs::{Data, LogDensityOptions, Model, Outputs};
use stan_model_rs_fixtures::NormalScale;

// data { real<lower=0> y; }  parameters { real<lower=0> sigma; }
// model { sigma ~ exponential(1); y ~ normal(0, sigma); }
let data = Data::from_json_str(r#"{"y": 0.4}"#).unwrap();
let model = NormalScale::new(&data).unwrap();

assert_eq!(model.num_unconstrained(), 1);
assert_eq!(model.param_names(Outputs::ALL), ["sigma"]);

// The sampler works on z = log(sigma); the density includes the Jacobian term z.
let (lp, grad) = model.log_density_gradient(&[0.25], LogDensityOptions::SAMPLING).unwrap();
let sigma = model.param_constrain(&[0.25]).unwrap()[0];
assert!((sigma - 0.25f64.exp()).abs() < 1e-15);
println!("log density {lp}, gradient {grad:?}");
```

Run the examples with `cargo run -p stan-model-rs --example evaluate`.

## Crates

| Crate | Contents |
| --- | --- |
| `stan-model-rs` | The runtime: `StanModel` (implemented by model code), `Model` (used by inference code), metadata, data, transforms, random numbers, and an optional `nuts-rs` adapter (feature `nuts`) |
| `stan-model-rs-fixtures` | Hand-written reference models that implement the contract the way generated code does |
| `stan-model-rs-stanc` | An adapter for models generated by stanc-rs today, and end-to-end tests that compile Stan programs with stanc-rs |

## Validation

* Closed-form log densities and gradients for the reference models of the specification.
* CmdStan 2.40 `log_prob` values (Stan C++) at fixed points, matched to 1e-12.
* stanc-rs generated code compiled at build time and compared with the hand-written models.
* Jacobian adjustments compared with numerical log determinants of the transforms.
* Gradients against finite differences, Hessians against differenced gradients.
* Round trips of every supported transform, property-based tests, and thread safety tests.
* A NUTS run with `nuts-rs` that reproduces a closed-form posterior.

See [docs/numerical-validation.md](docs/numerical-validation.md) for details and
[docs/compatibility.md](docs/compatibility.md) for the differences from Stan.

## Building

Rust 1.85 or later. `cargo test --workspace` runs every test; `cargo test -p stan-model-rs
--features nuts` adds the sampler test; `cargo bench -p stan-model-rs` runs the benchmarks.
The workspace has no C++ dependencies.
